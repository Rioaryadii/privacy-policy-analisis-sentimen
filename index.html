Kebijakan Privasi Aplikasi Penelitian Analisis Sentimen

Terakhir diperbarui: 3 November 2026

1. Pendahuluan

Penelitian Analisis Sentimen adalah aplikasi yang dikembangkan untuk keperluan penelitian akademik mengenai opini masyarakat terhadap pelaksanaan Program Makan Bergizi Gratis (MBG) melalui konten publik pada platform Threads. Kebijakan ini menjelaskan informasi yang dapat diakses dan diproses dalam pelaksanaan penelitian.

2. Informasi yang Diproses

Dengan menggunakan akses Threads API dan izin yang diberikan Meta, penelitian dapat mengakses konten Threads yang tersedia secara publik. Informasi yang dipilih untuk dataset penelitian dibatasi pada informasi yang diperlukan, seperti:

  • teks atau isi postingan;
  • tanggal publikasi postingan;
  • kata kunci yang digunakan dalam pencarian; dan
  • ID postingan, apabila diperlukan untuk pemeriksaan data atau penghapusan duplikasi.

Dataset penelitian tidak dirancang untuk mengumpulkan atau menyimpan username, foto profil, maupun informasi profil pengguna sebagai variabel penelitian. Namun, informasi teknis tertentu yang disediakan API, termasuk identifier atau token akses, dapat diproses sementara apabila diperlukan untuk menjalankan integrasi API.

3. Tujuan Pemrosesan Data

Informasi digunakan untuk kepentingan akademik, khususnya:

  • menganalisis opini publik terkait pelaksanaan program MBG;
  • mengelompokkan sentimen menjadi positif, negatif, dan netral;
  • membandingkan algoritma Naive Bayes dan Support Vector Machine (SVM); dan
  • mengevaluasi model menggunakan accuracy, precision, recall, F1-score, serta confusion matrix.

Data tidak digunakan untuk iklan, penjualan data, atau pembuatan profil komersial terhadap pengguna Threads.

4. Penyimpanan dan Keamanan Data

Dataset penelitian disimpan secara lokal pada perangkat komputer peneliti, misalnya dalam format CSV atau Excel. Aplikasi penelitian ini tidak dirancang untuk mengunggah dataset ke database cloud atau penyimpanan publik. Peneliti akan menerapkan langkah perlindungan yang wajar terhadap file penelitian dan kredensial akses API, termasuk membatasi akses perangkat dan tidak membagikan token akses kepada pihak yang tidak berwenang.

5. Pembagian dan Pengungkapan Data

Dataset tidak diperjualbelikan atau disewakan. Hasil penelitian dapat disajikan dalam proposal, laporan, presentasi, atau publikasi akademik. Penyajian hasil akan diupayakan dalam bentuk agregat dan tidak mencantumkan identitas akun individu. Pemrosesan oleh Meta saat penggunaan Threads API tetap tunduk pada ketentuan dan kebijakan Meta.

6. Retensi dan Penghapusan Data

Data disimpan selama diperlukan untuk menyelesaikan penelitian dan memenuhi kebutuhan akademik. Setelah tidak lagi diperlukan, file lokal akan dihapus atau disimpan hanya sejauh dibutuhkan untuk dokumentasi akademik yang sah. Peneliti juga akan memperhatikan ketentuan penyimpanan dan penghapusan data yang berlaku pada platform dan sumber data.

7. Layanan Pihak Ketiga

Penelitian ini menggunakan Threads API yang disediakan oleh Meta. Akses dan penggunaan API tunduk pada ketentuan layanan, kebijakan developer, izin yang disetujui, dan kebijakan privasi Meta.
